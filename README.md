# Lume Odontologia (site demo)

Site demonstrativo feito pela Lowex. Clínica fictícia: todos os dados marcados como "exemplo" são ilustrativos.

## Publicar no GitHub Pages
1. Crie um repositório e envie todos os arquivos desta pasta (o `index.html` precisa ficar na raiz).
2. No repositório: Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / pasta `/ (root)` > Save.
3. Em 1 a 2 minutos o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

A tag `noindex` impede que o Google indexe a demo. Remova antes de usar em um cliente real.
